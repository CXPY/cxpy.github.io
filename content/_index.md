# VTK DICOM Viewer - 医学影像查看器演示

基于 **VTK (Visualization Toolkit)** 开发的 DICOM 医学影像查看器，支持多平面重建和 CT 值调节功能。

## 功能特性

- **DICOM 数据加载**: 支持批量加载 DICOM 序列图像
- **三平面视图**: 同时显示横断面 (Axial)、矢状面 (Sagittal)、冠状面 (Coronal) 三个视角
- **CT 值调节**: 根据组织密度调整窗宽窗位，可清晰观察骨骼等高密度结构
